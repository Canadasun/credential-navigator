1. How it works

Credential Navigator has four parts, all started together by one command (Figure 1). The portal is the website applicants see. It sends their answers to the API, which compares them with the regulator data held in a PostgreSQL database and sends back a roadmap. Nothing about the applicant is stored: the database holds only the regulators' rules.

Portal (port 3010): Next.js website in English and French; forwards /api/* calls to the API.

API (port 8010): FastAPI service that builds roadmaps and reads uploaded PDFs, with Tesseract OCR for scans.

Database (port 5433): PostgreSQL with the requirements, fees, timelines and syllabi of APEGA, the CRNA, the ACP and CIPS.

Data loader: checks the regulator files, then loads them in one go when the system starts.

Where the rules come from

No AI writes or changes the rules. A person reads each official page and records the fact with its link and date; the files are validated before loading, and a weekly check flags any page that changes (Figure 2).

2. Start and stop

  1. Make sure Docker Desktop is running.
  2. Open a WSL terminal and run:
    cd /mnt/c/Users/M70Q/Desktop/CredentialNavigator && ./scripts/start.sh
  3. When it prints Ready, your browser opens http://localhost:3010. The first start takes 2–3 minutes; later starts take under a minute.

9. Everything else

  • ☐ Every requirement has a Source link that opens the regulator's page.
  • ☐ The yellow Advisory tool note is on every page and names all four organizations.
  • ☐ Phone view: press F12, then Ctrl+Shift+M, and choose a phone. Nothing should be cut off or scroll sideways.
  • ☐ Keyboard only: Tab moves through every question and button with a visible blue outline; Space selects Yes / No / Not sure.
  • ☐ API: at http://localhost:8010/docs open POST /roadmap/crna → Try it out → send {"nclex_passed": true}.
  • ☐ Drafts: tick Save my answers on this browser, answer a question, reload: "Saved answers restored on this browser." Delete saved draft, reload: the answers are gone.
  • ☐ After a roadmap: Print / save PDF shows only the report; Download report (JSON) saves a file.
  • ☐ Editing any answer after a roadmap clears it (it must reflect the current answers).
  • ☐ Validation: the date box refuses future dates; via the API, an IELTS score of 12 or a test together with an exemption is refused with a readable message.
  • ☐ Stop with ./scripts/start.sh --stop and start again: it comes back with the data already loaded.

10. Automated checks (optional)

With the system running, from the frontend folder: npm install --no-save playwright @axe-core/playwright && npx playwright install chromium && node tests/e2e.cjs. It opens Chromium and runs 11 checks: all four professions, the three uploads, privacy, French, accessibility and phone width. HEADLESS=1 node tests/regressions.cjs adds 15 regression scenarios (drafts, stale results, validation, export).

If anything doesn't match this guide, note the scenario number and what you saw. That's all I need to find and fix it.
